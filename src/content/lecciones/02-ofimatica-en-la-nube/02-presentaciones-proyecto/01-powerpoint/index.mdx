# PowerPoint vs. Canva

## Propósito de la clase

PowerPoint y Canva son herramientas. Ninguna convierte automáticamente una idea en una buena presentación. En esta sesión aprenderás a organizar una idea, convertirla en apoyo visual y elegir la herramienta más conveniente para comunicarla.

La pregunta central no es **“¿cuál es mejor?”**, sino:

> **¿Cuál me conviene para lo que quiero hacer?**

## Resultados de aprendizaje

Al finalizar la sesión, el estudiante podrá:

- [ ] Explicar la diferencia entre una presentación y un documento.
- [ ] Aplicar reglas básicas de legibilidad, contraste, alineación y consistencia.
- [ ] Crear una presentación de seis diapositivas o páginas.
- [ ] Insertar y organizar texto, imágenes, formas y capas.
- [ ] Diferenciar una transición de una animación.
- [ ] Usar notas del presentador o una alternativa para no llenar las diapositivas de texto.
- [ ] Seleccionar PowerPoint o Canva justificando su elección.

## 1. Introducción: una presentación no es un documento

### Activación

Muestra una diapositiva deliberadamente mala titulada **“Los videojuegos”**:

- párrafo enorme;
- Comic Sans o varias tipografías mezcladas;
- texto con poco contraste;
- imágenes estiradas;
- demasiados colores y animaciones.

Pregunta al grupo: **“¿Esta presentación es buena? ¿Por qué?”**

Después explica:

> **Una presentación es un apoyo visual para comunicar información a una audiencia. No es un documento que debamos leer.**

Escribe en el pizarrón:

**Presentación ≠ documento**

Un documento contiene el detalle completo. Una presentación conserva las ideas que ayudan a explicar ese detalle.

### Ejemplo rápido

**Malo: documento en una diapositiva**

> Pokémon es una franquicia creada en 1996 que consiste en una serie de videojuegos desarrollados principalmente por Game Freak y publicados por Nintendo...

**Mejor: apoyo visual**

# Pokémon

**Una franquicia basada en tres ideas:**

**Capturar → Entrenar → Combatir**

Agrega una imagen que ayude a comprender la idea y explica el resto oralmente.

## 2. Diseño básico de una buena diapositiva

Usa estas reglas como lista de comprobación:

1. Una idea principal por diapositiva.
2. Menos texto suele ser mejor.
3. El texto debe leerse desde lejos.
4. Debe existir contraste entre fondo y texto.
5. Las imágenes deben aportar información, no rellenar espacio.
6. Los elementos deben estar alineados.
7. Mantén colores y tipografías consistentes.
8. Las animaciones deben ayudar a explicar, no distraer.

Aclara que **contenido y diseño son cosas distintas**: primero se decide qué se quiere comunicar y después cómo se verá.

## 3. PowerPoint desde cero

### Interfaz mínima

No recorras todos los botones. Ubica solo las zonas que se usarán:

| Zona | Para qué sirve |
| --- | --- |
| Panel de diapositivas | Orden y estructura |
| Área central | Edición de la diapositiva |
| Cinta de opciones | Herramientas disponibles |
| Inicio | Texto y formato |
| Insertar | Imágenes, formas, tablas y gráficos |
| Diseño | Apariencia general |
| Transiciones | Cambio entre diapositivas |
| Animaciones | Movimiento dentro de una diapositiva |
| Presentación | Mostrar el trabajo |
| Notas | Apoyo para quien expone |

### Demostración guiada: “Minecraft”

Comienza con **Presentación en blanco** para mostrar qué constituye una diapositiva.

#### Diapositiva 1: portada

Contenido:

```text
Minecraft
Por [nombre]
```

Demuestra cómo cambiar tamaño, fuente, color, posición y fondo. Repite la idea: el contenido responde **qué decir** y el diseño responde **cómo ayudar a entenderlo**.

#### Diapositiva 2: ¿qué es Minecraft?

Incluye un título, una imagen y tres palabras:

**Explorar · Construir · Sobrevivir**

En **Insertar → Imágenes**, muestra cómo:

- cambiar el tamaño sin deformar;
- mover y recortar;
- conservar proporciones;
- alinear con otros elementos.

Estira una imagen intencionalmente y pregunta: **“¿Qué le pasó a Steve?”**

#### Diapositiva 3: formas y tarjetas

Construye tres tarjetas:

| Exploración | Construcción | Multijugador |
| --- | --- | --- |
| mapa | bloques | equipo |

Usa **Insertar → Formas** y demuestra relleno, borde, texto, duplicar, alinear y distribuir.

#### Capas

Coloca una forma encima de una imagen y prueba **Traer al frente** y **Enviar atrás**. Explica que los elementos están apilados como hojas de papel.

#### Tabla o gráfico

Muestra brevemente una tabla de horas jugadas y conviértela en un gráfico sencillo:

| Juego | Horas |
| --- | ---: |
| Minecraft | 300 |
| Fortnite | 120 |
| Pokémon | 200 |

Aclara que PowerPoint resulta especialmente útil cuando se necesita trabajar con información estructurada, académica o empresarial.

#### Transiciones y animaciones

Explica la diferencia:

- **Transición:** ocurre entre diapositivas.
- **Animación:** ocurre dentro de una diapositiva.

Primero muestra una transición exagerada y después usa **Desvanecer**. Para animaciones, crea tres elementos y haz que aparezcan uno por uno:

| Inicio | Significado |
| --- | --- |
| Al hacer clic | La persona que expone decide cuándo aparece |
| Con anterior | Aparece al mismo tiempo que el elemento anterior |
| Después de anterior | Aparece automáticamente |

La animación debe mantener la atención en la idea que se está explicando.

#### Notas del presentador

En las notas escribe información que el público no necesita leer:

**Diapositiva:** `Minecraft cambió los videojuegos sandbox.`

**Notas:** `Fue desarrollado originalmente por Markus Persson y posteriormente adquirido por Mojang.`

Explica que la vista del presentador puede mostrar al expositor la diapositiva actual, la siguiente y sus notas, mientras el público solo ve la presentación.

#### Presentar

Demuestra:

- **F5:** iniciar desde el principio;
- flechas o espacio: avanzar;
- **Esc:** salir;
- **B:** poner temporalmente la pantalla en negro.

La presentación debe apoyar a quien expone; no reemplazarlo.

## 4. Canva desde cero

Ahora crea la misma presentación en Canva para que la comparación sea justa.

### Interfaz mínima

Selecciona **Crear diseño → Presentación 16:9** y comienza con una presentación vacía.

Relaciona los conceptos:

| PowerPoint | Canva |
| --- | --- |
| Diapositiva | Página |
| Insertar | Elementos, texto y archivos subidos |
| Traer al frente / enviar atrás | Posición |
| Presentación | Presentar |

### Demostración guiada

Repite la portada de Minecraft con cuadro de texto, fuente, tamaño, color, alineación y efectos.

Después muestra:

- **Elementos:** iconos, formas, ilustraciones, gráficos y stickers;
- **Fotos** o **Subidos:** imágenes propias y recursos disponibles;
- **Marcos:** arrastrar una imagen dentro de una forma;
- **Posición:** adelante, atrás, alineación y distribución;
- **Animar:** aplicar una animación a un elemento o a una página;
- **Presentar:** iniciar la exposición;
- **Compartir:** distinguir entre permiso para ver y permiso para editar;
- **Descargar:** elegir enlace, formato editable o PDF según el objetivo.

Advierte que Canva mezcla recursos gratuitos y de pago. Para la actividad se debe asumir Canva Free; cualquier función adicional es opcional.

### Plantillas

Usa una plantilla solo después de comprender la estructura vacía. Busca, por ejemplo, `Gaming presentation` y explica:

> **Una plantilla es un punto de partida, no una presentación terminada.**

Hay que cambiar el texto, las imágenes, los colores y la información. No se debe entregar una plantilla cambiando únicamente el nombre.

## 5. Comparación razonada

Después de probar ambas herramientas, compara:

| Criterio | PowerPoint | Canva |
| --- | --- | --- |
| Crear rápidamente | Bueno | Excelente |
| Plantillas | Muchas | Muchísimas |
| Diseño visual | Muy bueno | Excelente |
| Control preciso | Excelente | Bueno |
| Animaciones avanzadas | Excelente | Más sencillo |
| Tablas y gráficos | Excelente | Bueno |
| Colaboración | Sí | Excelente |
| Trabajo sin conexión | Excelente en escritorio | Principalmente orientado a la nube |
| Presentaciones escolares o empresariales | Excelente | Excelente |
| Redes sociales y diseño rápido | Limitado | Excelente |
| Facilidad inicial | Fácil | Muy fácil |

Conclusión:

- **PowerPoint:** ofrece mucho control sobre diseño, animación, notas y presentación.
- **Canva:** permite llegar rápidamente a un resultado visual y facilita el trabajo con plantillas y colaboración.

Ninguna herramienta es universalmente mejor. La elección depende del objetivo, el tiempo, el nivel de control y la forma de trabajo.

## 6. Reto práctico: “Véndeme algo que te guste”

Elige un videojuego, película, anime, deporte, hobby, serie, artista, libro o tecnología. El objetivo es convencer al grupo de probarlo.

### Producto esperado

Una presentación de **seis diapositivas o páginas**, creada en PowerPoint o Canva:

| Diapositiva | Contenido |
| ---: | --- |
| 1 | Portada |
| 2 | ¿Qué es? |
| 3 | ¿Por qué es interesante? |
| 4 | Tres características |
| 5 | Imagen o dato destacado |
| 6 | Conclusión y llamado a probarlo |

### Condiciones

- mínimo tres imágenes o recursos visuales;
- evitar párrafos largos;
- colores y tipografías coherentes;
- al menos una transición;
- al menos una animación con propósito;
- exposición oral de 2 a 3 minutos;
- no usar una plantilla sin modificarla;
- justificar brevemente la elección de PowerPoint o Canva.

### Secuencia de trabajo

1. Elige el tema y escribe la idea principal.
2. Organiza las seis diapositivas antes de decorar.
3. Agrega texto breve e imágenes que aporten información.
4. Revisa alineación, contraste, legibilidad y consistencia.
5. Agrega una transición y una animación moderada.
6. Practica la explicación sin leer cada palabra.
7. Exporta o comparte el resultado con permisos correctos.

## 7. Presentaciones y retroalimentación

Cada estudiante o equipo presenta durante 2 a 3 minutos. El grupo puede responder:

- ¿Cuál era la idea principal?
- ¿Qué recurso visual ayudó más?
- ¿Qué parte tenía demasiado texto o movimiento?
- ¿La herramienta elegida fue adecuada? ¿Por qué?

### Evaluación: 10 puntos

| Criterio | Puntos |
| --- | ---: |
| Información clara | 2 |
| Organización de las seis diapositivas | 2 |
| Diseño y legibilidad | 2 |
| Uso de recursos visuales | 2 |
| Exposición oral | 2 |
| **Total** | **10** |

No se asignan puntos por usar Canva o PowerPoint. La herramienta es secundaria; se evalúa qué tan bien se comunicó la idea.

## Errores comunes y recomendaciones

- **Párrafos largos:** convertirlos en una idea principal y palabras clave.
- **Imagen deformada:** cambiar el tamaño desde una esquina o usar recorte.
- **Poco contraste:** probar el texto sobre un fondo más simple u oscuro.
- **Elementos desalineados:** usar las opciones de alinear y distribuir.
- **Demasiadas animaciones:** conservar solo las que guían la explicación.
- **Confundir transición y animación:** recordar que una cambia de diapositiva y la otra afecta elementos internos.
- **Leer toda la diapositiva:** usar notas del presentador y practicar la explicación.
- **Compartir con permisos incorrectos:** comprobar si la otra persona puede ver o editar.
- **Usar una plantilla sin cambios:** modificar estructura, texto, imágenes y colores.

## Cierre y verificación

Pregunta al grupo:

1. ¿Qué diferencia existe entre una presentación y un documento?
2. ¿Cuándo elegirías PowerPoint?
3. ¿Cuándo elegirías Canva?
4. ¿Qué hace que una animación ayude en vez de distraer?
5. ¿Qué evidencia demuestra que tu presentación comunica una idea?

Cierra con esta idea:

> **No existe una herramienta universalmente mejor. Existe una herramienta más adecuada para cada situación y para cada persona.**

### Lista de cotejo final

- [ ] La presentación tiene una idea principal clara.
- [ ] Las seis diapositivas siguen una secuencia lógica.
- [ ] El texto puede leerse sin esfuerzo.
- [ ] Las imágenes aportan información.
- [ ] Los colores y las tipografías son consistentes.
- [ ] La transición y la animación tienen un propósito.
- [ ] La persona puede explicar el trabajo sin leerlo completo.
- [ ] El archivo o enlace funciona y tiene permisos correctos.
