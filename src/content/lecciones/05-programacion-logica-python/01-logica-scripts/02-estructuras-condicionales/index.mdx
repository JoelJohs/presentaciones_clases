# Estructuras de Control Condicional

Tus primeros programas ejecutaban cada instrucción en orden secuencial sin desvíos. Con las estructuras condicionales, la computadora evalúa datos y selecciona qué camino de código ejecutar.

Resuelve cada expresión en tu libreta antes de revisar el resultado:

- `10 > 5` produce `True`.

## 3. El Rombo de Decisión en Diagramas de Flujo <Icon name="lucide:git-fork" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

El rombo representa una bifurcación en el flujo del algoritmo.

### Reglas de dibujo

1. Una flecha entra por la punta superior.
2. Salen dos flechas: una por la punta derecha y otra por la punta inferior o izquierda.
3. Etiqueta una flecha con `SÍ` y la otra flecha con `NO`. Ningún rombo tiene tres salidas.

### Tres patrones de bifurcación

1. **Bifurcación simple:** Ejecuta un bloque de instrucciones si la condición se cumple. Si la condición resulta falsa, la línea de flujo salta el bloque y continúa el recorrido.
2. **Bifurcación doble:** Divide la ejecución en dos caminos exclusivos. Un camino corre con `SÍ` y el camino opuesto corre con `NO`.
3. **Bifurcación múltiple (cascada):** La rama del `NO` conecta con un nuevo rombo de decisión. Permite clasificar datos en tres o más rangos sucesivos.

## 4. Estructura de Pseudocódigo Formal <Icon name="lucide:file-code" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

Escribe bifurcaciones en tu libreta con esta plantilla estructurada:

```text
SI condicion_1 ENTONCES
    // Instrucciones si condicion_1 es verdadera
SINO SI condicion_2 ENTONCES
    // Instrucciones si condicion_2 es verdadera
SINO
    // Instrucciones si ninguna condicion anterior se cumplio
FIN SI
```

### Reglas de escritura

- Agrega sangría en las instrucciones internas de cada bloque.
- Coloca la condición después de las palabras `SI` o `SINO SI`.
- La palabra `SINO` no lleva condición propia; captura todos los casos restantes.
- Cierra cada bloque condicional con `FIN SI`.

### Reglas de validación

- Usuario correcto: `"admin"`

## 8. Python al Silicio: Indentación y Trampas de Código <Icon name="lucide:alert-triangle" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

Python utiliza sangría obligatoria de 4 espacios y dos puntos `:` al final de cada encabezado condicional. No utiliza llaves ni palabras de cierre.

### Trampa 1: Asignar en lugar de comparar

```python
# ERROR: produce SyntaxError
if edad = 18:
    print("Tienes 18")

# CORRECTO: compara igualdad
if edad == 18:
    print("Tienes 18")
```

### Trampa 2: Orden erróneo en cascada

Python evalúa condiciones de arriba hacia abajo. Al encontrar una expresión verdadera, ejecuta ese bloque y salta todo el resto del grupo condicional.

```python
# ERROR LÓGICO: 65 es mayor o igual a 12, por lo que nunca alcanza la tarifa de adulto mayor
if edad >= 12:
    print("Tarifa regular")
elif edad >= 60:
    print("Tarifa adulto mayor")
```

Para corregir el flujo, evalúa primero la condición más restrictiva o acota rangos con comparadores claros.

## 9. Práctica en VS Code: Script de Taquilla de Cine <Icon name="lucide:play" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

Abre VS Code, crea el archivo `clasificador_cine.py` en tu carpeta de trabajo y escribe este script:

```python
print("=== TAQUILLA DEL CINE ===")
edad = int(input("Ingresa la edad del cliente: "))

if edad < 0 or edad > 120:
    print("Error: Edad fuera de rango válido.")
elif edad < 12:
    print("Categoría: Infantil")
    print("Monto a pagar: $45.00")
elif edad < 60:
    print("Categoría: Regular")
    print("Monto a pagar: $80.00")
else:
    print("Categoría: Adulto Mayor")
    print("Monto a pagar: $40.00")

print("Disfrute su función.")
```

Guarda el archivo (`Ctrl + S`) y ejecútalo desde la terminal integrada:

```bash
python3 clasificador_cine.py
```

Comprueba el script ingresando las edades de tu prueba de escritorio: `-3`, `10`, `35` y `68`. Verifica que cada respuesta coincida con lo calculado en tu libreta.

### Reglas comerciales

Una tienda de abarrotes aplica descuentos según el total de la compra:

- Compras menores a `$500.00`: `0%` de descuento. Paga el total completo.
- Compras desde `$500.00` hasta menos de `$1000.00`: `10%` de descuento (`total * 0.90`).
- Compras de `$1000.00` o más: `20%` de descuento (`total * 0.80`).

> [!WARNING]
> Ordena las evaluaciones con cuidado. Si evalúas `>= 500` antes de `>= 1000`, una compra de `$1200.00` entrará al bloque del 10% y no recibirá el 20%.
