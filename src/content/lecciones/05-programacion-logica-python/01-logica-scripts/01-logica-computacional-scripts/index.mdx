## 1. Instrucciones Secuenciales y Algoritmos <Icon name="lucide:cpu" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

La computadora obedece instrucciones paso a paso. No infiere intenciones ni corrige descuidos.

Un algoritmo cumple tres reglas:

- **Determinismo:** Los mismos datos de entrada generan el mismo resultado en cada ejecución.
- **Secuencialidad:** La máquina procesa una línea tras otra, de arriba hacia abajo.
- **Atomicidad:** Cada instrucción realiza una sola acción indivisible.

Un algoritmo es una secuencia finita, ordenada y clara de pasos para resolver un problema.

## 4. Pseudocódigo Base <Icon name="lucide:file-code" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

Usa tres verbos para escribir algoritmos en tu libreta:

- `MOSTRAR`: Imprime texto o variables en pantalla.
- `LEER`: Guarda lo que el usuario escribe en una variable.
- `<-`: Guarda el resultado de una operación en una variable.

```text
INICIO
    MOSTRAR "Ingresa tu nombre:"
    LEER nombre
    MOSTRAR "Hola, " + nombre + ". Cuenta activada."
FIN
```

## 5. Ejercicio 1: Generador de Nombres de Usuario <Icon name="lucide:user" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

Dibuja el diagrama de flujo en tu cuaderno y escribe el pseudocódigo:

- **Problema:** Pide el nombre y el color favorito del usuario. Une ambos datos con un guion bajo.
- **Objetivo:** Capturar cadenas (`str`) y concatenarlas sin operaciones matemáticas.

### Pseudocódigo

```text
INICIO
    MOSTRAR "¿Cómo te llamas?"
    LEER nombre
    MOSTRAR "¿Cuál es tu color favorito?"
    LEER color
    usuario_final <- nombre + "_" + color
    MOSTRAR "Tu usuario sugerido es: " + usuario_final
FIN
```

## 6. Ejercicio 2: Caja Registradora del Kiosco <Icon name="lucide:shopping-cart" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

Resuelve este ejercicio en tu cuaderno separando datos enteros de valores con punto decimal:

- **Problema:** Un cliente compra papas de `$18.50` y refrescos de `$16.00`. Pide la cantidad de cada producto, calcula el total y muestra el monto final.
- **Objetivo:** Combinar enteros (`cant_papas`, `cant_refresco`) con decimales (`precio_papas`, `precio_refresco`, `total`).

### Pseudocódigo

```text
INICIO
    precio_papas <- 18.50
    precio_refresco <- 16.00
    MOSTRAR "¿Cuántas bolsas de papas compraste?"
    LEER cant_papas
    MOSTRAR "¿Cuántos refrescos compraste?"
    LEER cant_refresco
    total <- (cant_papas * precio_papas) + (cant_refresco * precio_refresco)
    MOSTRAR "Total a pagar: $" + total
FIN
```

## 8. Entrada de Datos con input() y Conversión de Tipos <Icon name="lucide:alert-triangle" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

Escribe este código en `app.py`:

```python
num1 = input("Dame un número: ")
num2 = input("Dame otro número: ")
print("La suma es:", num1 + num2)
```

Al ingresar `5` y `5`, la consola muestra:

```text
La suma es: 55
```

La función `input()` devuelve texto (`str`), aunque escribas dígitos. El operador `+` entre textos los concatena en vez de sumarlos.

Para sumar cantidades, convierte el texto a número con `int()` o `float()`:

```python
num1 = int(input("Dame un número: "))
num2 = int(input("Dame otro número: "))
print("La suma real es:", num1 + num2)
```

Al ingresar `5` y `5`, el resultado es `10`.

## 9. De la Libreta al Código: Caja Registradora en Python <Icon name="lucide:play" class="inline w-6 h-6 align-text-bottom text-brand-primary" />

Traslada el Ejercicio 2 de tu libreta a Python en `app.py`:

```python
precio_papas = 18.50
precio_refresco = 16.00

cant_papas = int(input("¿Cuántas bolsas de papas compraste? "))
cant_refresco = int(input("¿Cuántos refrescos compraste? "))

total = (cant_papas * precio_papas) + (cant_refresco * precio_refresco)

print("=== TICKET DE PAGO ===")
print("Total a pagar: $", total)
```

Guarda el archivo (`Ctrl + S`) y ejecútalo en la terminal integrada:

```bash
python3 app.py
```

Si compras 2 bolsas de papas y 2 refrescos, el total en pantalla debe ser `$69.0`.
